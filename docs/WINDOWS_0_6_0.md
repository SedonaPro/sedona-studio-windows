# Windows 0.6.0

Локальная мастерская поддерживает Sedona и C-киты для комплектного classic Win32 SDK (32-битная VM, refSize=4), включая несколько native-kit таблиц. Компилятор и заголовки входят в поставку. Внешние Linux/Python/C-компилятор для этого режима не требуются.

Исходники native-китов создаются через окно мастерской в app/sdk/src/studio-native. Кнопки сборки и тестирования сохраняют открытый файл перед компиляцией. Ошибки C указывают строку в исходнике; при ошибке прежние бинарный кит, манифест и VM остаются рабочими. Каждая успешная VM получает отдельное имя; native-vm.txt переключается атомарно. Запущенный симулятор перезапускают вручную.

Во время занятой операции локальные команды ожидают её завершения вместо диалога «Дождитесь завершения операции». Перемещение, свойства, отмена и повтор обрабатываются одинаково. Если устройство вернуло другую структуру или операция завершилась ошибкой, команды не переносятся на другую структуру; строка состояния просит повторить действие. Это очередь локального редактирования, а не повтор сетевых записей.

Ограничения: сторонние C-киты с Linux API и аппаратными функциями требуют отдельного порта. Другие ABI и прошивки контроллеров комплектным Win32-компилятором не собираются.

LLVM-MinGW: https://github.com/mstorsjo/llvm-mingw/releases/tag/20240619 . Контрольная сумма исходного архива — app/c-toolchain/dependency.json, лицензии — app/c-toolchain/LICENSE.TXT и включённые каталоги. Промежуточные экспериментальные архивы не входят в релиз.
