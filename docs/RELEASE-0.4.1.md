# Sedona Studio 0.4.1 — один проект

API, виджеты и стенд перенесены внутрь G:\SedonaStudio\modules. Сохраняется модульная граница для независимой разработки, но проект, сборка, тесты, документация и выпуск теперь общие.

build.py автоматически собирает все части. build.py --panel-only пересобирает только виджеты против готового API без изменения JAR редактора. test.py включает проверки внутренних модулей. Стенд запускается Start-Panel-Demo.cmd в проекте или Panel-Demo.cmd в Windows-поставке.

Весь код включён в один архив исходников, редактор и панель — в один Windows-выпуск. Копия G:\SedonaPanel и прежние выпуски сохранены как архив; для сборки не требуются. Исходники при переносе сверены по SHA-256. Панель по-прежнему READ-only на реальном устройстве, текущая функциональность и данные сессий не менялись.
