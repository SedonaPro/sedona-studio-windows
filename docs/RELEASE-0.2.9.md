# Sedona Studio 0.2.9

Опции → Устройство → Сравнить с последним чтением: отдельный просмотр без записи и без обязательного соединения. Для сравнения нужен снимок, прочитанный в текущем окне; после отключения он остаётся доступен. Открытие сохранённого проекта само по себе не создаёт исходный снимок контроллера.

В списке изменений есть поиск без учёта регистра по имени, полю, источнику/приёмнику связи, старому и новому значению. Фильтр по типу: добавление, изменение, удаление. Счётчик показывает показанные и все строки, отдельно суммируя виды изменений. Это количество строк сравнения, а не количество сетевых операций.

Фильтр не исключает операции из записи. На вкладке плана всегда полный план. Подтверждение явно называется «Применить весь план». В отдельном просмотре только кнопка закрытия, нет записи и App.save. Отмена применения не меняет проект и состояние опроса.

Сравнение не перечитывает устройство и не останавливает онлайн-опрос. Перед фактическим применением сохранена свежая проверка, резервные копии и журнал. Если план для проекта недоступен, просмотр показывает причину, но не разрешает запись.

Все версии и промежуточные исходники сохранены. Запуск: G:\SedonaStudio\Start-SedonaStudio.cmd. Предыдущие окна закрыть перед запуском новой версии.
