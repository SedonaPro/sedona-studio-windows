Windows Java runtime: minimal OpenJDK 17 image created with jlink; upstream notices remain in runtime/legal. JavaFX: OpenJFX 17.0.12, GPLv2 with Classpath Exception; see OPENJFX-LICENSE.html and lib/javafx/dependencies.json for pinned public Maven artifacts. The sedona.sox.SchemaParts class is a small package-level adapter for the existing Sedona request API, reused from our Java web project. No web server is included.
