# Sedona Studio 0.2.8

После «Применить» откройте вкладку «Схемы»: слева последний прочитанный снимок, справа подтверждаемый проект. Это просмотр копий без сетевых запросов и редактирования. Перед самой записью остаётся свежая проверка драйвера.

Зелёный и +: добавленные блоки/связи; красный и −: удалённые; янтарный и Δ: изменённые блоки и узлы изменённых связей. Поля read-only и секреты не участвуют в классификации изменений. Значения на схемах — из снимков, без онлайн-опроса; секретные поля маскируются.

Есть выбор папок из обоих снимков, общая шкала масштаба, «Вписать обе схемы». В «Опциях сравнения»: значения из снимков, синхронная прокрутка и приглушение неизменённых блоков. Эти три опции запоминаются. По умолчанию значения скрыты, прокрутка синхронная, неизменённые блоки приглушены.

Геометрия сохраняет координаты снимков без автоматического разведения: так видно перемещение блоков. Наложения, уже присутствующие в проекте, видны и в сравнении. Список «Было → будет» и полный план остаются на соседних вкладках.

Схемы создаются при первом открытии вкладки. Сложная маршрутизация пока выполняется в UI-потоке; испытаний на слабом ПК и реальных контроллерах в этом выпуске не было.

Запуск: G:\SedonaStudio\Start-SedonaStudio.cmd. Старые окна нужно закрыть. Предыдущие выпуски сохранены.
