# Sedona Studio 0.3.0 — завершение текущего этапа

- Общая библиотека шаблонов: сохранение выделения/поддерева, внутренние связи, поиск, импорт/экспорт, вставка с undo и удаление в архив.
- Проверка точных китов и доступности типов палитры до вставки. Кэши манифестов остаются изолированными.
- Журнал операций текущей сессии: попытки, DONE, последний неизвестный шаг, сохранённые копии и историческое сравнение без записи.
- Явное перечитывание после сбоя сохраняет текущий черновик дополнительно в recovery-drafts.

Подробности и ограничения: USER_GUIDE_RU.md. Совместимость шаблонов консервативна: сохраняется полный точный набор китов исходного проекта. Автоматическое повторение/откат частичной записи не выполняется.

Предыдущие выпуски, исходники и контрольные копии сохранены. Реальные устройства в этом выпуске не менялись.
