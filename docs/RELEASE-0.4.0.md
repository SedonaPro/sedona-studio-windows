# Sedona Studio 0.4.0 — независимая панель

Панель выделена в G:\SedonaPanel: отдельные API 1.0.0, модуль/стенд 0.1.0, сборка, тесты и документ. Studio содержит только адаптер и загрузчик JAR. Виджеты зависят только от API/JDK/JavaFX, исходники Studio не нужны. API совместимость проверяется при загрузке.

Справа добавлена вкладка «Панель» с первыми виджетами значения и Boolean. Наблюдаемые поля используют общий последовательный опрос; отдельного подключения и фонового транспорта у виджетов нет. Панель сохраняется отдельно по сессиям. Производственный адаптер READ-only; методы команд предусмотрены, но возвращают отказ. В самостоятельном демостенде команды работают с искусственным состоянием.

Проверены независимая сборка/запуск/восстановление документа, DTO и контракты, сохранение/изоляция/подписки адаптера, локальные SOX данные через API, отсутствующий/несовместимый/дублирующий API модуль, реальная вкладка, прежние UI-функции и переключение сессий. Физические устройства не изменялись.

Это архитектурное выделение и минимальная библиотека отображения. Полноценная раскладка, новые виджеты и производственные кнопки/actions остаются отдельным развитием модуля и адаптера.
