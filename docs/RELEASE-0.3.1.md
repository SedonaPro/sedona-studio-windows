# Sedona Studio 0.3.1

Шаблоны требуют только подтверждённые зависимости: локальный расчёт прямых/транзитивных китов, sys и типов портов. Источником версий служит только набор исходного проекта. При недоступных/несовместимых манифестах остаётся весь исходный набор; скачивания и подстановки checksum не выполняются. Старые шаблоны анализируются на копии без перезаписи оригинала. В библиотеке показываются причина консервативного режима и точные киты для вставки.

Вставка ищет свободное место для всей группы в текущей папке, сохраняет относительные позиции, вложенные координаты и опорные точки внутренних связей. Существующие блоки не перемещаются. Первый вставленный блок выводится в область просмотра; при отсутствии места операция завершается без изменения проекта. Ctrl+Z отменяет вставку целиком.

Проверены точные и транзитивные зависимости реальных локальных манифестов, исключение лишнего кита, отсутствие подмены checksum, сохранение набора при недоступном манифесте, конфликт версий, размещение и маршруты. Проверены UI библиотеки/сравнения/журнала через упакованный EXE. Сетевой протокол и реальное устройство в этом выпуске не изменялись. Длительные испытания и слабый ПК остаются отложенными.

Исходники: G:\SedonaStudio\src. Запуск: G:\SedonaStudio\Start-SedonaStudio.cmd. Предыдущие выпуски сохранены.
