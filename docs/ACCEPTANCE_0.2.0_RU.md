# Проверка первых двух этапов — 0.2.0

Реализованные возможности и ограничения описаны в README_RU.md, раздел 0.2.0.

Воспроизводимые проверки:

1. `python -X utf8 build.py`
2. `python -X utf8 test.py --local-sox --live-ui`
3. `python -X utf8 tests/workspace_smoke.py`
4. runtime/bin/java.exe --add-modules javafx.controls,javafx.swing -Dstudio.root=<отдельная тестовая папка> -jar dist/SedonaStudio/sedona-studio.jar --smoke

Тестовые процессы используют отдельные профили и только локальный native SVM на 13987. Не заменять адрес физическим контроллером.

Критерии: группы и маршруты отменяются одним действием; копирование сохраняет внутренние связи; перенос сохраняет внешние связи и группы доступа; опрос не изменяет draft/undo и не пересчитывает маршрут; состояния свежести соответствуют возрасту/паузе/локальному изменению; вкладки возвращаются в тот же процесс без смешивания каталогов; скрытые сессии завершаются при закрытии рабочего окна. Повреждённый черновик восстанавливается без потери исправной резервной копии и повреждённого оригинала.

Следующая проверка на реальном стенде: удобство жестов на фактической схеме, длительная работа с несколькими устройствами и замер памяти/задержек на слабом ПК. Изменение приложения физического контроллера требует отдельного осознанного Apply.
