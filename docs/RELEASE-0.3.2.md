# Sedona Studio 0.3.2

В библиотеке появился отдельный просмотр шаблона до вставки: одна схема, выбор папки, масштаб и вписывание, собственная опция сохранённых значений. Открывается кнопкой или двойным щелчком. Просмотр использует копию и штатный расчёт геометрии, не редактирует проект, не подключается к устройству и не рассчитывает вторую скрытую диаграмму.

Добавлено переименование с сохранением прежнего файла в `.bak`. Меняется только название: блоки, связи, координаты и набор китов сохраняются. При некорректном имени файл не меняется. Команды библиотеки переносятся по ширине окна.

Проверены операции хранения/переименования и фактические кнопки библиотеки: просмотр, закрытие, переименование, дальнейшая вставка и undo. Обычное сравнение и диалоги записи также проверены. Реальные контроллеры не затрагивались; сетевой протокол не менялся.

Исходники: G:\SedonaStudio\src. Запуск: G:\SedonaStudio\Start-SedonaStudio.cmd. Предыдущие выпуски и контрольные копии сохранены.
